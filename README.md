A make.fun bounty entry. The program writes one word describing my Wi-Fi to `/output/entry.txt`.

## The word

> peekaboo

My Wi-Fi plays peekaboo — the signal is here, then gone, then back again, always when I need it most.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The entry is checked by a self-authored `validate()` gate that mirrors the bounty gate: UTF-8 text, 1 to 20 characters, not only whitespace, exactly one word.
